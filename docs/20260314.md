# 📅 2026-03-14 연구 개발 일지: QEC AlphaZero Search 고도화

## 1. 🧪 시뮬레이션 및 엄격한 평가 모듈 구축 (`sim/stim_interface.py`)
* **Stim & PyMatching 연동:** 구글의 양자 시뮬레이터 `Stim`과 MWPM 디코더 `PyMatching`을 활용하여, 실제 물리적 노이즈(Depolarizing Channel) 환경에서의 논리 에러율(Logical Error Rate)을 측정하는 `StimEvaluator` 클래스 구현.
* **에이전트 꼼수(Reward Hacking) 차단:** * 쌍대성 검증: X 에러와 Z 에러 중 더 취약한 쪽(Worst-case)의 에러율을 반환하도록 설정.
  * 반교환성 검증: 유효한 양자 코드가 되기 위한 필수 조건인 $L_X$, $L_Z$ 쌍의 존재 여부를 GF(2) 선형대수학으로 엄밀히 검증.

## 2. ⚖️ 강화학습 보상 체계(Reward System) 최적화
* **고립 큐비트 패널티(No Orphan Qubits):** 에이전트가 에러율을 낮추기 위해 일부 물리 큐비트를 논리 연산에서 아예 배제해버리는 꼬리 자르기 꼼수를 방지하기 위해, 안정자와 연결되지 않은 큐비트가 발생 시 강한 음의 보상 부여.
* **희소성(Sparsity) 기반 보상 도입 (qLDPC 원리):**
  * 인간의 시각적 편향인 '대칭성(Symmetry) 강제 룰'을 배제.
  * 양자 저밀도 패리티 검사(qLDPC) 코드의 핵심 원리인 '선 밀도 최소화(CNOT 게이트 수 최소화)'를 보편적 보상으로 채택하여, 에러 전파(Error Propagation)를 줄이는 범용적인 코드를 스스로 탐색하도록 유도.

## 3. ⚙️ MLOps 파이프라인 및 실험 재현성 확보
* **난수 시드(Seed) 고정 및 자동화:** `argparse`를 도입하여 터미널에서 `--seed`로 실행을 통제. 시드 미입력 시 기존 `outputs` 폴더를 분석하여 겹치지 않는 시드를 자동 할당하는 로직 추가.
* **학습 히스토리 추적 로직:** 덮어쓰기(`PermissionError`) 문제를 해결하고 진화 과정을 관찰하기 위해, 신기록이 나올 때마다 `best_codes_epc{}_ep{}` 형태로 개별 폴더에 박제. 100 Epoch 종료 후 가장 우수한 결과물만 `final_codes`로 통합.
* **학습률 스케줄러(StepLR):** 최적화 과정의 효율을 높이기 위해 30 에포크마다 학습률을 절반으로 줄이는 스케줄러 도입.

## 4. 📁 아키텍처 모듈화 및 시각화 개선
* **프로젝트 디렉토리 구조 개편:** * 실행 스크립트(`train.py`, `train.ipynb`)를 `train/` 폴더로 분리.
  * 학습 핵심 클래스(`AlphaZeroTrainer`)를 `train/module/trainer.py`로 모듈화.
  * `sys.path` 절대 경로 매핑(`PROJECT_ROOT`)을 통해 모듈 간 패키지 인식 문제(ModuleNotFoundError) 및 폴더 저장 경로 충돌 완벽 해결.
* **SVG 회로도 시각화 개선:** VS Code 다크 모드 환경 등에서도 양자 회로도가 명확히 보이도록 SVG 렌더링 시 최상단 태그에 흰색 배경(`background-color:white;`) 강제 주입.

## 💡 주요 발견 및 인사이트
* AlphaZero 에이전트가 단 100 에포크 내외의 탐색만으로 이론상 최적에 가까운 **Steane [[7, 1, 3]] 코드의 동형(Isomorphic) 구조를 스스로 재발견**함.
* 베이스라인 노이즈($p=0.01$) 환경에서 논리 에러율을 **0.0056** 수준으로 획기적으로 낮추는 결함 허용(Fault-tolerant) 구조 도출에 성공.
* 시각적으로는 비대칭이어도 수학적으로는 완벽한 방어력을 가지는 기하학적 얽힘(Isomorphism)의 본질을 AI가 스스로 증명함.
