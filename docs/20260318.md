# 📅 2026-03-18 Research Log: QEC AlphaZero 하드웨어 토폴로지 제약 및 탐색 공간 최적화

## 🎯 1. 연구 목표 (Objective)
* **과도한 자유도로 인한 탐색 붕괴(Curse of Dimensionality) 해결:** AI가 물리적으로 불가능한 장거리 큐비트 연결을 시도하며 학습에 실패하는 현상 개선.
* **하드웨어 친화적 탐색(Hardware-Aware Search):** 실제 7x7 초전도 양자 칩 구조에 맞춘 인접 큐비트 간 연결만 허용하도록 환경 모델링 수정.
* **편향 노이즈(Biased Noise) 테스트 기반 마련:** X 에러와 Z 에러 비율을 다르게 주입하여 비대칭 QEC 코드를 자가 학습할 수 있는 시뮬레이션 환경 구축.

## 🛠️ 2. 핵심 트러블슈팅 및 아키텍처 개편

### 2.1. 하드웨어 토폴로지 마스킹 (Topology Masking) 도입
* **이슈:** 기존 환경에서는 AI가 (1,1) 위치의 큐비트와 (5,5) 위치의 안정자를 직접 연결하는 등, 물리적 현실과 동떨어진 선을 긋느라 경우의 수($2^{72}$)의 늪에 빠짐.
* **해결:** `envs/qec_env.py`에 `_build_topology_mask`를 도입하여, 물리적으로 인접한 큐비트 쌍(Manhattan Distance = 2)만 `action_mask=1`로 활성화.
* **결과:** AI의 탐색 공간이 수조 배 이상 획기적으로 축소되어, 오직 에러율($P_L$) 최적화에만 집중할 수 있게 됨. 이에 따라 `reward_calculator.py`에서 불필요한 거리 계산 패널티 로직을 완전히 삭제하여 경량화.

### 2.2. 편향 노이즈(Biased Noise) 평가 시스템 구축
* **이슈:** 기존 `stim_interface.py`는 X, Y, Z 에러가 동일한 확률로 발생하는 Uniform Depolarizing Noise만 지원함.
* **해결:** 노이즈 주입 함수 인자를 `noise_rate_x`와 `noise_rate_z`로 분리.
* **기대 효과:** Z 에러가 압도적으로 많이 발생하는 실제 물리적 양자 프로세서 환경을 모사하여, AI가 기존 학계를 뛰어넘는 맞춤형(Tailored) 비대칭 QEC 코드를 발명하도록 유도할 수 있는 무기 장착.

### 2.3. 신기록 저장 조건 완화 (Break-even 제약 해제)
* **이슈:** 99 에포크에서 위반(Violation) 0개 및 에러율 1.4%(0.0140)를 달성한 유효 코드를 찾아냈으나, 저장 조건이 너무 빡빡하여(`err < 0.01`) 시각화 데이터가 저장되지 않고 유실됨.
* **해결:** `trainer.py`의 신기록 저장 조건을 `err_01 < 1.0`으로 완화.
* **결과:** 1.0(완전 실패)만 아니면 일단 유효 코드로 간주하여 `best_codes` 폴더에 시각화 이미지(Tanner Graph, 2D Grid 등)를 저장함으로써 연구자의 디버깅 인사이트 확보.

### 2.4. Value Loss '0.0000' 붕괴 현상과 "제출(Submit)" 액션 트릭
* **이슈:** 토폴로지 마스킹 도입 직후, `Val Loss`가 0.0000으로 떨어지며 학습이 정체되는 과적합 버그 발생. AI에게 '에피소드 종료(Submit)' 버튼이 없어, 허용된 30여 개의 칸을 무조건 다 채운 똑같은 형태의 코드만 뱉어냈기 때문.
* **해결:** 신경망 차원 수정 없이 기발한 RL 트릭 도입. `qec_env.py`의 `action_mask`에서 **이미 1로 칠해진 선을 마스킹하지 않고 열어두어, AI가 이를 재선택할 경우 "제출(에피소드 즉시 종료)"로 간주**하도록 `step()` 함수 수정.
* **결과:** AI가 12줄, 18줄, 24줄 등 다양한 길이의 회로를 실험하고 원할 때 제출할 수 있게 되어, Value Loss의 분산이 회복되고 정상적인 강화학습 탐색 재개됨.
