# 2026-03-15 연구 일지 (Part 2: Hardware-Aware QEC & 학습 최적화)

## 1. 이론적 통찰 및 문제 정의
* **교환 법칙과 대칭성의 오해 해소:** 단일 데이터 큐비트 입장에서 X, Z 안정자의 개수가 짝이 맞지 않아도(비대칭), 전체 $H_X \cdot H_Z^T \equiv 0 \pmod 2$ (짝수 교차)만 성립하면 수학적으로 유효한 QEC 코드임을 수식으로 직접 검증함.
* **스파게티 배선(Spaghetti Wiring) 문제:** 교환 법칙만 지킨 AI의 코드는 수학적으로는 완벽하나, 실제 2D 양자 칩에서는 무수한 SWAP 게이트를 유발하여 에러를 폭발시키는 하드웨어적 결함을 가짐을 확인.
* **시각화의 함정 발견:** 파노 평면(Fano Plane) 시각화 도구는 노드 위치가 삼각형으로 강제 고정되어 있어, AI가 2D 격자상에서 최적화한 짧은 배선도 길고 복잡하게(왜곡되어) 보이게 만든다는 사실을 파악함.

## 2. 보상 체계(Reward System) 전면 개편
**목표:** 단순 에러율 감소를 넘어, 칩 위의 물리적 배선 길이를 최소화하는 하드웨어 친화적 코드 발굴.
* **Auto-Grid 기반 2D 기하학적 거리 패널티:** 큐비트와 안정자 수에 맞춰 자동으로 가상의 2D 격자(예: $4 \times 4$)를 생성하고, 선을 연결할 때마다 맨해튼 거리(Manhattan Distance)를 계산하여 가치 점수(Value)를 감점하는 로직 추가.
* **다중 노이즈 강건성 평가:** 고정된 1% 노이즈 환경뿐만 아니라, 구글 Willow 프로세서 스펙(0.1%) 및 가혹 환경(5%)을 동시 채점하여 특정 환경 과적합(Overfitting) 방지 (`stim_interface.py` 업데이트).
* **CNOT 최소화 (Sparsity) 보상 강화:** 거리가 짧을수록, 게이트 수가 적을수록 최종 보상이 극대화되도록 산식 개편.

## 3. 신경망 최적화 및 동적 밸런싱 (수학적 고도화)
**목표:** 뇌 굳음(고원 현상)을 방지하고, Policy(MCTS 모방)와 Value(에러율 방어) 사이의 완벽한 학습 균형 달성.



* **AdamW 옵티마이저 도입:** 가중치 감쇠(Weight Decay)를 분리하여 AI가 특정 꼼수에 과적합되는 것을 막고 지속적인 탐색 유도.
* **Cosine Annealing LR 스케줄러:** 에포크가 진행될수록 학습률(0.001 -> 0.00001)을 부드럽게 감소시켜, 최적 코드 발견 시 미세조정(Fine-tuning) 및 안정적인 소프트 랜딩 보장.
* **불확실성 기반 동적 가중치 (Uncertainty Weighting):** Policy Loss의 스케일이 Value Loss를 압도하는 문제를 해결하기 위해, 신경망 내부에 학습 가능한 파라미터(`log_var_v`, `log_var_p`)를 도입. AI가 두 Loss의 불확실성을 스스로 평가하여 실시간으로 가중치를 조절($W_{Val}$, $W_{Pol}$)하도록 설계 (Kendall et al. CVPR 2018 논문 방식 적용).
* **데이터 소화량(Batch Iteration) 증가:** 에피소드당 학습 횟수를 20회에서 100회로 늘려, MCTS가 수집한 데이터를 신경망이 충분히 복습하고 가치를 정밀하게 판단할 수 있도록 조치.
