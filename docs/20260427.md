# 🚀 GFlowNet 기반 QLDPC (BB 코드) 생성 아키텍처 설계서

본 문서는 양자 오류 정정(QEC) 코드, 특히 Bivariate Bicycle(BB) 코드 구조 탐색을 위한 새로운 강화학습(RL) 프레임워크의 설계 철학과 세부 구현 방안을 정의합니다. 기존 MCTS(AlphaZero) 기반의 한계를 극복하고, 최신 생성형 탐색 모델인 GFlowNet을 도입합니다.

---

## 1. 문제의 재정의: 고전적 조합 최적화로의 치환

양자 회로 설계의 얽힌 물리적 제약들을 수학적으로 엄밀한 고전 그래프 이론 문제로 치환하여 접근합니다.

*   **A. 오일러 부분 그래프 (Eulerian Subgraph) 문제**
    *   **개념:** 모든 노드의 차수(Degree)가 짝수인 그래프(중국인 우체부 문제의 필수 조건)를 찾는 문제.
    *   **QEC 매칭:** $H_X H_Z^T \equiv 0 \pmod 2$ (교환 법칙). 특정 큐비트 집합을 공유하는 X, Z 안정자의 수는 항상 짝수여야 한다는 절대적 물리 제약과 완벽히 일치합니다.
*   **B. 용량이 제한된 라우팅 문제 (Capacitated VRP)**
    *   **개념:** 각 노드별로 연결 가능한 선의 최대 개수가 엄격하게 제한된 네트워크 구축 문제.
    *   **QEC 매칭:** 하드웨어 토폴로지 상의 Row/Column Weight 제한 (데이터 큐비트는 최대 2개, 안정자는 최대 4개의 연결만 허용).
*   **C. 조건부 희소 그래프 생성 (Constrained Sparse Graph Generation)**
    *   **개념:** 특정 크기 이하의 순환 고리(Cycle)가 발생하지 않도록 엣지를 배치하는 문제.
    *   **QEC 매칭:** 짧은 에러 전파 고리인 **Girth-4**를 최소화하여 코딩 이득(Coding Gain)을 극대화하는 최적화 목표와 동일합니다.

## 2. GFlowNet 아키텍처 도입 (Macro-Architecture)

단 하나의 최적해를 찾는 기존 RL의 한계(Policy Freeze)를 벗어나, 제약 조건을 만족하는 **'다양한 고성능 QEC 코드들을 확률적으로 생성'**하는 프레임워크로 전환합니다.

*   **상태 공간 (State Space): 1D 다항식 시프트 배열**
    *   더 이상 2D 픽셀 격자에 CNOT을 하나씩 긋지 않습니다.
    *   상태는 BB 코드의 블록 순환 행렬(Circulant Matrix)을 정의하는 **시프트 값 배열(예: $[s_1, s_2, s_3, s_4]$)**로 극단적으로 압축됩니다.
    *   이로 인해 탐색 공간의 복잡도가 우주적 규모에서 다루기 쉬운 수준으로 급감합니다.
*   **행동 공간 (Action Space):**
    *   특정 시프트 값을 $+1$ 또는 $-1$ 조정하는 행동.
    *   탐색을 종료하고 평가를 요청하는 **`Submit` (제출)** 행동 분리.
*   **모델 구조:** 1D-CNN 또는 MLP 기반의 Feature Extractor + Trajectory Balance(TB) Loss 기반 최적화. (가치망 Value Network 폐기)

## 3. 보상 체계의 고도화 (Reward System Design)

GFlowNet의 필수 조건인 **"모든 종료 상태의 보상은 0보다 큰 양수(Strictly Positive)여야 한다"**는 원칙 아래, 허들형 비선형 곱셈 보상(Multiplicative Reward) 체계를 구축합니다.

### 3.1. 하드 제약(Hard Constraint)의 환경(Env) 이관
*   Row/Column Weight 초과와 같은 규칙은 보상 함수에서 감점하는 대신, **Action Masking**을 통해 물리적으로 선택 불가능하게 만듭니다. 이를 통해 AI가 무의미한 탐색에 에너지를 낭비하는 것을 원천 차단합니다.

### 3.2. 허들형 곱셈 보상 (Multiplicative Reward)
문법(Feasibility)과 성능(Performance)을 분리하여 계층적으로 평가합니다.
$$R_{total} = R_{feasibility} \times R_{performance}$$

1.  **$R_{feasibility}$ (문법 - 교환 법칙 평가):**
    *   $R_{feasibility} = \exp(-\beta_1 \cdot \text{Violations}^2)$
    *   비선형 스케일링(제곱)을 적용하여, 정답에 근접할수록(위반 개수가 줄어들수록) 보상의 상승폭이 기하급수적으로 커지도록 유도합니다. 위반이 1개라도 있으면 이 값은 극소값(예: $0.001$)이 됩니다.
2.  **$R_{performance}$ (성능 - 에러율 평가):**
    *   $R_{performance} = \exp(+\beta_2 \cdot \text{SinterScore} - \beta_3 \cdot \text{Girth}_4)$
    *   문법을 완벽히 통과한($R_{feasibility} \approx 1.0$) 코드에 한정하여, 물리적 에러 방어력과 Girth-4 억제력에 비례하는 잭팟 보상을 부여합니다.

### 3.3. 온도 스케줄링 (Temperature Annealing)
*   **탐험기 (초기 에포크):** $\beta$ 값을 낮게 설정하여($High \ Temperature$), 페널티의 충격을 완화하고 AI가 시프트 공간 전체를 넓게 훑어보도록(Exploration) 유도합니다.
*   **수렴기 (후반 에포크):** $\beta$ 값을 높여($Low \ Temperature$), 교환 법칙을 완벽히 만족하는 유효한 코드 주변에서 미세 조정을 통한 성능 극대화(Exploitation)에 집중시킵니다.

## 4. 기대 효과 및 연구 기여 (Contribution)

1.  **탐색 병목 해결:** MCTS의 무거운 시뮬레이션 의존도를 제거하고 TB Loss 기반의 초고속 샘플링을 달성.
2.  **구조적 모순 해결:** 하드 제약(문법)과 소프트 제약(성능)을 분리하여 AI의 '보상 해킹(Reward Hacking)' 및 로컬 미니마(Local Minima) 함정 회피.
3.  **다양성 확보:** GFlowNet의 생성적 특성을 통해, Sinter 에러율 한계점(Threshold)을 돌파할 수 있는 **다양한 후보 BB 코드군**을 동시다발적으로 발굴.
