## 🧠 3. 환경 및 보상 체계 개선 (Environment & Reward Shaping)

### 3.1. 기하학적 모순 해결: Rotated Surface Code 맞춤형 격자 매핑
* **이슈:** 기존 Unrotated 가정으로 인해 AI가 기하학적 모순에 빠져 학습을 포기함.
* **해결:** 완벽한 패리티(Parity) 매핑 규칙 재정립.
  * 데이터 큐비트는 무조건 `(홀수, 홀수)` 좌표에 배치.
  * 안정자 큐비트는 무조건 `(짝수, 짝수)` 좌표에 배치.
  * 대각선 연결 구조를 반영하여 최적 하드웨어 거리를 `MD=2`로 재설정 (`optimal_distance = total_cnots * 2`).

### 3.2. 지수적 희망고문 (Exponential Reward Shaping) 도입
* **이슈:** $H_X$, $H_Z$ 직교성을 맞출 확률이 희박하여 100 Epoch 내내 유효한 코드를 찾지 못함 (Sparse Reward).
* **해결:** 위반(Violation) 개수가 줄어들수록 패널티가 0에 가깝게 기하급수적으로 감소하도록 설계 (`violation_ratio ** 3`). 위반이 1~2개 남았을 때 약소한 양수 보상(+0.2)을 주어 정답 도달을 유도.

### 3.3. 불필요한 패널티 배제 (미래 확장성 고려)
* **안정자 차수(Weight) 제한 배제:** BB Code 등 qLDPC는 Weight-6 이상을 적극 활용하므로, 4 초과 시 패널티를 주는 것은 미래 확장성을 저해한다고 판단. 기존 `sparsity_penalty`로 대체.
* **회로 깊이(Depth) 보상 배제:** 에러율($P_L$) 최소화라는 본질을 흐리고 AI의 Reward Hacking을 유발할 수 있어 기각.

## 🔍 4. 트러블슈팅 (Troubleshooting)

### 📌 Total Loss 음수 현상 분석 및 조치
* **증상:** 훈련 중 `Total Loss`가 -1.9 이하로 곤두박질치는 현상.
* **원인:** 다중 작업 학습의 **동적 가중치(Uncertainty Weighting)** 알고리즘이 정상 작동한 결과. AI가 예측이 쉬운 Value Network의 Loss 비중을 지수함수적으로 폭증시키기 위해 파라미터 $s$를 큰 음수로 조정하면서 발생 ($L = \exp(-s) \cdot L_{base} + s$).
* **조치:** 시각적 안정성 및 모니터링 직관성을 위해 `torch.clamp`의 하한선을 `-6.0`에서 `-2.0`으로 상향 조정하여 가중치 폭발 방지.
