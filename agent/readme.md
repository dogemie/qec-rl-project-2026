# 🧠 AlphaZero Agent (`agent/`)

이 디렉토리는 양자 오류 정정(QEC) 코드를 스스로 설계하고 탐색하는 인공지능의 "뇌(Brain)"에 해당하는 핵심 강화학습 알고리즘을 포함하고 있습니다.

구글 딥마인드(DeepMind)의 **AlphaZero 아키텍처**를 기반으로 하며, 인간의 편향(Bias)이나 사전 지식 없이(Tabula Rasa) 순수한 수학적/물리적 제약 조건 속에서 최적의 양자 얽힘 구조를 발명해 냅니다.

## 📂 핵심 컴포넌트

### 1. `network.py` (`QECNet`)
* **역할:** 현재 양자 코드의 상태(State)를 평가하는 심층 신경망.
* **구조:** 두 개의 '머리(Head)'를 가진 Two-headed Network 구조입니다.
  * **Policy Head (정책 신경망):** 현재 상태에서 어떤 큐비트와 안정자(Stabilizer)를 연결하는 것이 가장 유망한지(Action Probabilities) 확률을 예측합니다.
  * **Value Head (가치 신경망):** 현재 그려진 패리티 행렬 구조가 최종적으로 얼마나 낮은 논리 에러율(Logical Error Rate)을 달성할 수 있을지(-1.0 ~ 1.0) 평가합니다.

### 2. `mcts.py` (`MCTS` - Monte Carlo Tree Search)
* **역할:** 신경망의 직관(Prediction)을 바탕으로 수많은 미래의 경우의 수를 미리 시뮬레이션하는 탐색기.
* **작동 원리 (PUCT 알고리즘):** * 단순히 무작위로 탐색하는 것이 아니라, 신경망이 추천한 확률(Prior)이 높은 길을 우선적으로 탐색합니다.
  * 동시에 아직 가보지 않은 낯선 구조(새로운 QEC 코드의 가능성)를 탐색하도록 '탐색(Exploration)과 활용(Exploitation)'의 균형을 완벽하게 맞춥니다.
  * 탐색이 끝나면 신경망의 예측보다 훨씬 정교해진 행동 확률 분포(Improved Policy)를 반환하여 에이전트의 성장을 돕습니다.

## 🚀 워크플로우 (Workflow)
1. **자기 주도 학습:** MCTS가 `QECNet`의 가이드를 받아 가상의 패리티 행렬을 조립합니다.
2. **평가 및 피드백:** 완성된 행렬은 물리적 시뮬레이터(Stim)의 채점을 받습니다.
3. **가중치 업데이트:** 시뮬레이터의 점수(실제 에러율)를 정답지로 삼아, `QECNet`이 자신의 Policy와 Value 예측을 교정하며 점점 더 정교한 양자 물리학자로 진화합니다.
